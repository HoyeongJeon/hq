# HQ MVP 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 바탕화면 바로가기로 여는 HQ 전용 창에서, 등록한 Windows 서버에 PowerShell 원격(WinRM 5985)으로 들어가 여러 탭으로 명령을 치고 결과를 보는 프로그램을 만든다.

**Architecture:** `hq.exe`(Python) 하나가 pywebview(WebView2) 창을 띄우고, 창 안의 화면(HTML/JS + xterm.js)과 같은 프로세스 안의 함수 호출로만 주고받는다(네트워크 포트 없음). 서버 탭마다 ConPTY 안에서 진짜 `powershell.exe`를 띄워 부트스트랩 스크립트로 `New-PSSession` → `Enter-PSSession` 하고, 출력·입력을 그대로 중계한다. 서버 목록은 `inventory.json`, 비밀번호는 DPAPI 파일로 `%LOCALAPPDATA%\hq`에만 둔다.

**Tech Stack:** Python 3.12, uv, pywinpty 3.0.5(ConPTY), pywebview 6.2.1(WebView2), openpyxl 3.1.5, xterm.js 5.5.0(@xterm/xterm) + @xterm/addon-fit 0.10.0, pytest + pytest-timeout, node 24 내장 `node --test`, PyInstaller.

**Spec:** `docs/specs/2026-10-15-hq-design.md` (승인됨). 이 계획은 스펙을 근거로 한다. 실행하는 사람은 두 문서를 함께 읽는다.

## Global Constraints

- 대상 PC: Windows 11, 클라이언트 셸은 Windows PowerShell 5.1(`%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe`). 서버에 붙여넣는 스크립트는 PowerShell 2.0 문법만 쓴다.
- Python `>=3.12,<3.13`. 의존성: `pywinpty>=3.0.5`, `pywebview>=6.2.1`, `openpyxl>=3.1.5`. 개발: `pytest>=8.3.0`, `pytest-timeout>=2.3.1`, `ruff>=0.8.0`, `pyinstaller>=6.11.0`, `pillow>=11.0.0`.
- hq는 네트워크 수신 포트를 하나도 열지 않는다. pywebview에는 반드시 `file:///` 주소를 준다(`http://`나 상대 경로를 주면 pywebview가 내부 웹 서버를 띄운다).
- 모든 정보는 `%LOCALAPPDATA%\hq`에만 둔다. 공유·동기화 기능은 만들지 않는다.
- 비밀번호는 명령줄, 환경 변수, 로그, 화면으로 돌려주는 값 어디에도 나오지 않는다(테스트 코드의 시험용 값은 예외).
- 사용자에게 보이는 글(화면, 오류 메시지, 스크립트 출력)은 한국어로 쓴다.
- 화면에 넣는 사용자 자료(이름, 별명, host, 메모 등)는 `textContent`나 텍스트 노드로만 넣는다. `innerHTML`은 쓰지 않는다.
- 사용자가 직접 실행하는 `.ps1`(`scripts/`, `tools/`)은 UTF-8 **BOM 포함**으로 저장한다. Windows PowerShell 5.1은 BOM 없는 파일을 ANSI로 읽어 한글이 깨진다. `src/hq/ps/`의 템플릿은 Python이 읽으므로 BOM 없이 두고 `utf-8-sig`로 읽는다.
- Claude는 실서버 비밀번호를 다루지 않는다. 실서버가 필요한 확인은 ⛔ 체크포인트에서 사용자가 하고 결과를 붙여 준다.
- TDD: 기능 코드보다 테스트를 먼저 쓰고, 기대한 이유로 실패하는 것을 확인한 뒤 구현한다. 커밋은 모든 테스트가 통과할 때만 한다.
- 커밋 메시지는 영어 제목 + 필요하면 본문. Claude/AI 표시(`Co-Authored-By` 등)를 넣지 않는다. git identity는 전역 설정을 쓰고 저장소 설정을 만들지 않는다.
- 테스트 명령: 전체 `uv run pytest`, 빠른 것만 `uv run pytest -m "not integration"`, 화면 로직 `node --test tests/js/`.

## Review Focus

스펙이 직접 말하지 않지만 사용자가 실제로 부딪히기 쉬운 입력과 상황이다. 각 줄의 테스트는 해당 태스크에 들어 있다.

1. **빠른 타이핑과 붙여넣기 순서.** pywebview는 화면이 부른 함수마다 스레드를 따로 띄우므로 키 입력 호출의 순서가 뒤바뀔 수 있다. 친 순서 그대로 서버에 가야 한다 → Task 14의 입력 대기열 테스트.
2. **출력 폭주.** `dir C:\Windows\System32 -Recurse` 같은 수 MB 출력에도 글자가 빠지거나 섞이지 않고, 한 번에 보내는 양은 제한돼야 한다 → Task 12 출력 묶음 테스트, Task 13 펌프 테스트.
3. **특수 문자가 든 값.** 별명·메모·비밀번호에 `'` `"` `$` `` ` `` `;` 줄바꿈, 한글이 있어도 명령에 섞이지 않고 그대로 전달돼야 한다 → Task 3 DPAPI 왕복, Task 4 부트스트랩 매개변수, Task 15 `innerHTML` 금지 테스트.
4. **엑셀의 흔한 실수.** 숫자로 저장된 비밀번호(12345678 → 12345678.0), 빈 행, 바뀐 머리글, 파일 안 중복 host → Task 8 테스트.
5. **탭이 열린 서버를 고치거나 지움.** 정보 수정은 돌고 있는 세션을 건드리지 않고, 삭제는 그 서버의 탭을 모두 닫아야 한다 → Task 13 테스트.

```python
"""hq가 쓰는 폴더 위치. 개발 중과 PyInstaller로 묶은 exe 안에서 모두 맞는 경로를 준다."""

import os
import sys
from pathlib import Path


def data_dir() -> Path:
    """%LOCALAPPDATA%\\hq. 서버 목록, 비밀번호 파일, 로그가 모두 여기에만 있다."""
    base = os.environ.get("LOCALAPPDATA")
    if not base:
        raise RuntimeError("LOCALAPPDATA 환경 변수가 없습니다.")
    path = Path(base) / "hq"
    path.mkdir(parents=True, exist_ok=True)
    return path


def package_dir() -> Path:
    """hq 패키지 폴더. exe 안에서는 PyInstaller가 풀어 둔 임시 폴더 아래의 hq/."""
    frozen_root = getattr(sys, "_MEIPASS", None)
    if frozen_root:
        return Path(frozen_root) / "hq"
    return Path(__file__).resolve().parent


def resource(relative: str) -> Path:
    return package_dir() / relative


def index_url() -> str:
    """화면 파일의 file:// 주소. http 주소가 아니어서 pywebview가 내부 웹 서버(포트)를 띄우지 않는다."""
    return resource("static/index.html").as_uri()
```

```python
"""PowerShell 명령에 들어가는 값의 형식 검사.

host와 username은 접속 스크립트와 TrustedHosts 스크립트에 들어가므로, 따옴표·$·공백 같은

import re

_HOSTNAME_LABEL = re.compile(r"[A-Za-z0-9](?:[A-Za-z0-9-]{0,61}[A-Za-z0-9])?")
_DIGITS_AND_DOTS = re.compile(r"[0-9.]+")
_USER = re.compile(r"[A-Za-z0-9._-]{1,64}")
_PREFIX = re.compile(r"\.|[A-Za-z0-9._-]{1,64}")


class ValidationError(ValueError):
    """화면에 그대로 보여 줄 한국어 메시지를 담는다."""


def validate_host(value: str) -> str:
    host = value.strip()
    if not host:
        raise ValidationError("IP/호스트를 입력하세요.")
    if len(host) > 253:
        raise ValidationError("IP/호스트가 너무 깁니다(253자 이하).")
    if _DIGITS_AND_DOTS.fullmatch(host):
        try:
            ipaddress.IPv4Address(host)
        except ValueError:
            raise ValidationError(f"IPv4 주소 형식이 아닙니다: {host}") from None
        return host
    if not all(_HOSTNAME_LABEL.fullmatch(label) for label in host.split(".")):
        raise ValidationError(f"호스트 이름에는 영문, 숫자, 점(.), 하이픈(-)만 쓸 수 있습니다: {host}")
    return host


def validate_username(value: str) -> str:
    user = value.strip()
    if not user:
        raise ValidationError("ID를 입력하세요.")
    prefix, sep, name = user.rpartition("\\")
    if sep and not _PREFIX.fullmatch(prefix):
        raise ValidationError(f"ID 앞부분은 '.\\' 또는 '서버이름\\' 형식만 쓸 수 있습니다: {user}")
    if not _USER.fullmatch(name):
        raise ValidationError(f"ID에는 영문, 숫자, 점(.), 밑줄(_), 하이픈(-)만 쓸 수 있습니다(64자 이하): {user}")
    return user


def validate_ipv4(value: str) -> str:
    text = value.strip()
    try:
        return str(ipaddress.IPv4Address(text))
    except ValueError:
        raise ValidationError(f"IPv4 주소 형식이 아닙니다: {text}") from None
```

```python
"""서버별 비밀번호 파일. DPAPI(현재 Windows 사용자)로 암호화해 16진 문자열로 저장한다.

이 형식은 키 없이 쓴 ConvertFrom-SecureString의 출력과 같아서, 탭의 powershell.exe가
ConvertTo-SecureString으로 바로 읽는다. hq(Python)는 쓰기만 하고 풀지 않는다. 그래서
비밀번호가 명령줄·환경 변수·화면을 거치지 않는다.
"""

import ctypes
import os
import re
from ctypes import wintypes
from pathlib import Path

_ID = re.compile(r"[0-9a-f]{32}")


class _Blob(ctypes.Structure):
    _fields_ = [("cbData", wintypes.DWORD), ("pbData", ctypes.POINTER(ctypes.c_char))]


_crypt32 = ctypes.WinDLL("crypt32", use_last_error=True)
_kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)
_BLOB_FUNC_ARGS = [
    ctypes.POINTER(_Blob),
    ctypes.c_void_p,
    ctypes.POINTER(_Blob),
    ctypes.c_void_p,
    ctypes.c_void_p,
    wintypes.DWORD,
    ctypes.POINTER(_Blob),
]
_crypt32.CryptProtectData.argtypes = _BLOB_FUNC_ARGS
_crypt32.CryptProtectData.restype = wintypes.BOOL
_crypt32.CryptUnprotectData.argtypes = _BLOB_FUNC_ARGS
_crypt32.CryptUnprotectData.restype = wintypes.BOOL
_kernel32.LocalFree.argtypes = [ctypes.c_void_p]
_kernel32.LocalFree.restype = ctypes.c_void_p


def _call(func, data: bytes) -> bytes:
    buffer = ctypes.create_string_buffer(data, len(data))
    source = _Blob(len(data), ctypes.cast(buffer, ctypes.POINTER(ctypes.c_char)))
    result = _Blob()
    if not func(ctypes.byref(source), None, None, None, None, 0, ctypes.byref(result)):
        raise ctypes.WinError(ctypes.get_last_error())
    try:
        return ctypes.string_at(result.pbData, result.cbData)
    finally:
        _kernel32.LocalFree(ctypes.cast(result.pbData, ctypes.c_void_p))


def protect(plaintext: bytes) -> bytes:
    return _call(_crypt32.CryptProtectData, plaintext)


def _unprotect(blob: bytes) -> bytes:
    """테스트 확인용. 앱 흐름에서는 비밀번호를 풀지 않는다."""
    return _call(_crypt32.CryptUnprotectData, blob)


class SecretStore:
    def __init__(self, directory: Path) -> None:
        self._dir = directory

    def path_for(self, server_id: str) -> Path:
        if not _ID.fullmatch(server_id or ""):
            raise ValueError(f"잘못된 서버 id: {server_id!r}")
        return self._dir / f"{server_id}.dpapi"

    def save(self, server_id: str, password: str) -> None:
        if not password:
            raise ValueError("비밀번호가 비어 있습니다.")
        path = self.path_for(server_id)
        self._dir.mkdir(parents=True, exist_ok=True)
        temp = path.with_suffix(".tmp")
        temp.write_text(protect(password.encode("utf-16-le")).hex(), encoding="ascii")
        os.replace(temp, path)

    def has(self, server_id: str) -> bool:
        return self.path_for(server_id).is_file()

    def delete(self, server_id: str) -> None:
        self.path_for(server_id).unlink(missing_ok=True)
```

```python
import os
import subprocess
from pathlib import Path

POWERSHELL = str(
    Path(os.environ.get("SystemRoot", r"C:\Windows")) / "System32" / "WindowsPowerShell" / "v1.0" / "powershell.exe"

def run_ps(script: str, *, env: dict[str, str] | None = None, timeout: float = 60) -> subprocess.CompletedProcess[str]:
    encoded = base64.b64encode((_UTF8_OUTPUT + script).encode("utf-16-le")).decode("ascii")
    return subprocess.run(
        [POWERSHELL, "-NoLogo", "-NoProfile", "-NonInteractive", "-EncodedCommand", encoded],
        capture_output=True,
        text=True,
        encoding="utf-8",
        errors="replace",
        timeout=timeout,
        env={**os.environ, **(env or {})},
        check=False,
    )


def parse_errors(script_text: str, tmp_path: Path) -> list[str]:
    """PowerShell 5.1 파서로 문법 오류 메시지 목록을 돌려준다(없으면 빈 목록)."""
    target = tmp_path / "parse-target.ps1"

        "$text = [IO.File]::ReadAllText($env:HQ_PARSE_FILE, [Text.Encoding]::UTF8)\n"
        "[void][System.Management.Automation.Language.Parser]::ParseInput($text, [ref]$null, [ref]$errors)\n"
        "foreach ($e in $errors) { Write-Output $e.Message }\n"
    )
    result = run_ps(checker, env={"HQ_PARSE_FILE": str(target)})
```

```python
    NOT_TRUSTED = "NOT_TRUSTED"
    QUOTA = "QUOTA"
    SECRET_UNREADABLE = "SECRET_UNREADABLE"
    DISCONNECTED = "DISCONNECTED"
    UNKNOWN = "UNKNOWN"


_REASONS = {
    0: ExitReason.USER_EXIT,
    10: ExitReason.AUTH_FAILED,
    11: ExitReason.UNREACHABLE,
    12: ExitReason.NOT_TRUSTED,
    13: ExitReason.QUOTA,
    14: ExitReason.SECRET_UNREADABLE,
    20: ExitReason.DISCONNECTED,
}


def reason_for_exit(code: int | None) -> ExitReason:
    if code is None:
        return ExitReason.UNKNOWN
    return _REASONS.get(code, ExitReason.UNKNOWN)


@dataclass(frozen=True)
class BootstrapParams:
    host: str
    username: str
    nickname: str
    secret_path: str


def template_text() -> str:
    return resource("ps/bootstrap.ps1").read_text(encoding="utf-8-sig")


def prelude() -> str:
    """안전장치(prompt)와 오류 분류 함수만. 테스트가 접속 없이 이 부분을 돌린다."""
    text = template_text()
    return text[: text.index(MAIN_MARKER)]


def build_script(params: BootstrapParams) -> str:
    payload = {
        "host": validate_host(params.host),
        "username": validate_username(params.username),
        "nickname": params.nickname,
        "secret_path": params.secret_path,
    }
    encoded = base64.b64encode(json.dumps(payload, ensure_ascii=False).encode("utf-8")).decode("ascii")
    return template_text().replace(_PLACEHOLDER, encoded)


def powershell_exe() -> str:
    root = os.environ.get("SystemRoot", r"C:\Windows")
    return str(Path(root) / "System32" / "WindowsPowerShell" / "v1.0" / "powershell.exe")


def encoded_argv(script: str, *, no_exit: bool = True) -> list[str]:
    argv = [powershell_exe(), "-NoLogo", "-NoProfile"]
    if no_exit:
        argv.append("-NoExit")
    argv += ["-EncodedCommand", base64.b64encode(script.encode("utf-16-le")).decode("ascii")]
    return argv


def build_command(params: BootstrapParams) -> list[str]:
    return encoded_argv(build_script(params))
```

```python
"""통합 테스트용: ConPTY 안에서 명령을 돌려 (출력, 종료 코드)를 돌려준다."""

import threading
import time

from winpty import PtyProcess


def run_pty(argv: list[str], *, writes=(), timeout: float = 30.0) -> tuple[str, int | None]:
    """writes는 (시작 후 몇 초 뒤, 보낼 글자) 목록. 프로세스가 끝날 때까지 기다린다."""
    proc = PtyProcess.spawn(argv)
    chunks: list[str] = []

    def reader() -> None:
        while True:
            try:
                data = proc.read(4096)
            except EOFError:
                return
            chunks.append(data)
            if "\x1b[c" in data:
                proc.write("\x1b[?1;0c")  # ConPTY의 터미널 종류 질문에 xterm처럼 답한다

    threading.Thread(target=reader, daemon=True).start()
    start = time.monotonic()
    for delay, text in writes:
        time.sleep(max(0.0, start + delay - time.monotonic()))
        proc.write(text)
    while proc.isalive() and time.monotonic() - start < timeout:
        time.sleep(0.05)
    if proc.isalive():
        proc.terminate(force=True)
        raise TimeoutError(f"{timeout}초 안에 끝나지 않았습니다: {''.join(chunks)[-500:]}")
    time.sleep(0.3)
    return "".join(chunks), proc.exitstatus
```

```python
    uv run python -m hq.verify --host 10.0.1.21 --user Administrator --nick 웹01
    uv run python -m hq.verify --host 10.0.1.21 --user Administrator --try-users Administrator .\\Administrator WEB01\\Administrator

비밀번호는 사용자가 입력하고, 임시 폴더의 DPAPI 파일에만 잠시 있다가 끝나면 지워진다.
"""

import argparse
import base64

import json
import shutil

import sys

from pathlib import Path

from hq.bootstrap import BootstrapParams, build_command, encoded_argv, reason_for_exit
from hq.secret_store import SecretStore

STEPS = """\
새 PowerShell 창이 두 번 열립니다.

[1회차] 열린 창에서 차례로 확인하세요.
  1. 프롬프트가 [{host}]: [{nick}] PS ...> 모양인지 (V1, V2)
  2. ipconfig 와 Get-Service | Select-Object -First 5 의 한글이 깨지지 않는지 (V5 일부)
  3. exit 를 입력하면 창이 닫히고, 여기에 '종료 코드 0' 이 찍히는지 (V7 정상 종료)

[2회차]
  4. Stop-Process -Id $PID -Force 를 입력하세요. 그 세션의 서버 쪽 프로세스만 끝냅니다.
     창이 저절로 닫히고, 여기에 '종료 코드 20' 이 찍히는지 (V7 끊김)
"""


def username_check_script(host: str, usernames: list[str], secret_path: str) -> str:
    payload = {"host": host, "users": usernames, "secret": secret_path}
    encoded = base64.b64encode(json.dumps(payload, ensure_ascii=False).encode("utf-8")).decode("ascii")
    return (
        "[Console]::OutputEncoding = [Text.Encoding]::UTF8\n"
        f"$p = [Text.Encoding]::UTF8.GetString([Convert]::FromBase64String('{encoded}')) | ConvertFrom-Json\n"
        "$secure = ConvertTo-SecureString -String ((Get-Content -LiteralPath $p.secret -Raw).Trim())\n"
        "foreach ($u in $p.users) {\n"
        "    try {\n"
        "        $cred = New-Object System.Management.Automation.PSCredential($u, $secure)\n"
        "        $s = New-PSSession -ComputerName $p.host -Credential $cred -ErrorAction Stop\n"
        "        Remove-PSSession $s\n"
        '        Write-Output "[성공] $u"\n'
        "    } catch {\n"
        '        Write-Output "[실패] $u : $($_.FullyQualifiedErrorId)"\n'
        "    }\n"
        "}\n"
    )


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(prog="python -m hq.verify", description="HQ 실서버 검증")
    parser.add_argument("--host", required=True)
    parser.add_argument("--user", required=True)
    parser.add_argument("--nick", default="검증")
    parser.add_argument("--try-users", nargs="+", metavar="ID", help="V6: 차례로 시험할 ID 표기")
    args = parser.parse_args(argv)
    try:
        host = validate_host(args.host)
        user = validate_username(args.user)
        tries = [validate_username(u) for u in (args.try_users or [])]
    except ValidationError as exc:
        parser.error(str(exc))

    work = Path(tempfile.mkdtemp(prefix="hq-verify-"))
    try:
        store = SecretStore(work)
        server_id = uuid.uuid4().hex
        store.save(server_id, getpass.getpass(f"{user}@{host} 비밀번호(화면에 보이지 않음): "))
        secret = str(store.path_for(server_id))
        if tries:
            subprocess.run(encoded_argv(username_check_script(host, tries, secret), no_exit=False), check=False)
            return 0
        print(STEPS.format(host=host, nick=args.nick))
        command = build_command(BootstrapParams(host=host, username=user, nickname=args.nick, secret_path=secret))
        for round_no in (1, 2):
            input(f"[{round_no}회차] Enter를 누르면 창을 엽니다...")
            code = subprocess.Popen(command, creationflags=subprocess.CREATE_NEW_CONSOLE).wait()
            print(f"종료 코드 {code} → {reason_for_exit(code).value}")
        return 0
    finally:
        shutil.rmtree(work, ignore_errors=True)


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""서버 목록(inventory.json). 비밀번호는 여기에 두지 않는다(secret_store 참고)."""

import json
import os
import re
import shutil
import threading
import uuid
from collections.abc import Mapping, Sequence
from dataclasses import asdict, dataclass, replace
from pathlib import Path
from typing import Any

from hq.validation import ValidationError, validate_host, validate_ipv4, validate_username

VERSION = 1
UNGROUPED = "미분류"
_ID = re.compile(r"[0-9a-f]{32}")
_LIMITS = {"name": ("이름", 100), "nickname": ("별명", 50), "group": ("그룹", 50), "memo": ("메모", 4000)}


@dataclass
class Server:
    id: str
    name: str
    host: str
    username: str
    nickname: str = ""
    group: str = ""
    memo: str = ""

    @property
    def display_name(self) -> str:
        return self.nickname or self.name


class InventoryError(Exception):
    """서버 목록 파일을 읽거나 쓸 수 없을 때. 메시지는 화면에 그대로 보여 준다."""


def _text(raw: Mapping[str, Any], key: str) -> str:
    value = raw.get(key)
    return "" if value is None else str(value)


def clean_fields(raw: Mapping[str, Any]) -> dict[str, str]:
    """화면·엑셀에서 받은 값을 검사해 저장할 모양으로 만든다. 문제가 있으면 ValidationError."""
    fields = {
        "name": _text(raw, "name").strip(),
        "nickname": _text(raw, "nickname").strip(),
        "group": _text(raw, "group").strip(),
        "memo": _text(raw, "memo").replace("\r\n", "\n").replace("\r", "\n").strip(),
    }
    if not fields["name"]:
        raise ValidationError("이름을 입력하세요.")
    for key, (label, limit) in _LIMITS.items():
        if len(fields[key]) > limit:
            raise ValidationError(f"{label}은(는) {limit}자 이하로 입력하세요.")
    fields["host"] = validate_host(_text(raw, "host"))
    fields["username"] = validate_username(_text(raw, "username"))
    return fields


class Inventory:
    def __init__(self, path: Path) -> None:
        self._path = path
        self._servers: list[Server] = []
        self._admin_ips: list[str] = []
        self._broken = False
        self._lock = threading.RLock()

    @property
    def path(self) -> Path:
        return self._path

    @property
    def _bak(self) -> Path:
        return self._path.with_name(self._path.name + ".bak")

    @property
    def servers(self) -> list[Server]:
        with self._lock:
            return [replace(s) for s in self._servers]

    @property
    def admin_ips(self) -> list[str]:
        with self._lock:
            return list(self._admin_ips)

    def load(self) -> None:
        with self._lock:
            self._servers, self._admin_ips, self._broken = [], [], False
            if not self._path.exists():
                return
            try:
                data = json.loads(self._path.read_text(encoding="utf-8"))
                if data.get("version") != VERSION:
                    raise ValueError(f"알 수 없는 버전 {data.get('version')!r}")
                servers = [self._server_from(item) for item in data.get("servers", [])]
                ips = [validate_ipv4(ip) for ip in data.get("settings", {}).get("admin_ips", [])]
                hosts = [s.host.lower() for s in servers]
                if len(hosts) != len(set(hosts)):
                    raise ValueError("같은 IP/호스트가 두 번 있습니다")
            except (OSError, ValueError, TypeError, AttributeError) as exc:
                self._broken = True
                raise InventoryError(
                    f"서버 목록 파일을 읽을 수 없어 저장을 막았습니다: {self._path} ({exc}). "
                    f"직전 버전은 {self._bak} 에 있습니다."
                ) from exc
            self._servers, self._admin_ips = servers, ips

    @staticmethod
    def _server_from(item: Mapping[str, Any]) -> Server:
        server_id = _text(item, "id")
        if not _ID.fullmatch(server_id):
            raise ValueError(f"잘못된 서버 id {server_id!r}")
        return Server(id=server_id, **clean_fields(item))

    def _find(self, server_id: str) -> Server:
        for server in self._servers:
            if server.id == server_id:
                return server
        raise KeyError(server_id)

    def get(self, server_id: str) -> Server:
        with self._lock:
            return replace(self._find(server_id))

    def find_by_host(self, host: str) -> Server | None:
        key = host.strip().lower()
        with self._lock:
            for server in self._servers:
                if server.host.lower() == key:
                    return replace(server)
        return None

    def _check_host_free(self, host: str, except_id: str | None) -> None:
        key = host.lower()
        for server in self._servers:
            if server.id != except_id and server.host.lower() == key:
                raise ValidationError(f"이미 등록된 IP/호스트입니다: {host} ({server.display_name})")

    def add(self, raw: Mapping[str, Any]) -> Server:
        fields = clean_fields(raw)
        with self._lock:
            self._check_host_free(fields["host"], None)
            server = Server(id=uuid.uuid4().hex, **fields)
            self._servers.append(server)
            return replace(server)

    def update(self, server_id: str, raw: Mapping[str, Any]) -> Server:
        fields = clean_fields(raw)
        with self._lock:
            server = self._find(server_id)
            self._check_host_free(fields["host"], server_id)
            for key, value in fields.items():
                setattr(server, key, value)
            return replace(server)

    def remove(self, server_id: str) -> Server:
        with self._lock:
            server = self._find(server_id)
            self._servers.remove(server)
            return server

    def set_admin_ips(self, ips: Sequence[str]) -> None:
        cleaned = [validate_ipv4(ip) for ip in ips if ip.strip()]
        with self._lock:
            self._admin_ips = list(dict.fromkeys(cleaned))

    def save(self) -> None:
        with self._lock:
            if self._broken:
                raise InventoryError(f"서버 목록 파일이 깨져 있어 저장하지 않았습니다: {self._path}")
            data = {
                "version": VERSION,
                "settings": {"admin_ips": self._admin_ips},
                "servers": [asdict(s) for s in self._servers],
            }
            self._path.parent.mkdir(parents=True, exist_ok=True)
            temp = self._path.with_name(self._path.name + ".tmp")
            temp.write_text(json.dumps(data, ensure_ascii=False, indent=2) + "\n", encoding="utf-8")
            if self._path.exists():
                shutil.copy2(self._path, self._bak)
            os.replace(temp, self._path)
```

```python
@dataclass
class PreviewRow:
    row: int
    status: str  # "new" | "existing" | "error"
    fields: dict[str, str]
    password: str = field(default="", repr=False)
    error: str = ""


@dataclass
class Preview:
    id: str
    rows: list[PreviewRow]
    created: float


def build_preview(path: Path, inventory: Inventory, *, clock: Callable[[], float] = time.monotonic) -> Preview:
    rows: list[PreviewRow] = []
    first_row_of: dict[str, int] = {}
    for number, texts in read_rows(path):
        values = dict(zip(_KEYS, texts, strict=True))
        password = values.pop("password")
        try:
            fields = clean_fields(values)
            if not password:
                raise ValidationError("PW를 입력하세요.")
        except ValidationError as exc:
            rows.append(PreviewRow(number, "error", values, error=str(exc)))
            continue
        key = fields["host"].lower()
        if key in first_row_of:
            message = f"파일 안에서 IP/호스트가 중복됩니다({first_row_of[key]}행과 같음)."
            rows.append(PreviewRow(number, "error", fields, error=message))
            continue
        first_row_of[key] = number
        status = "existing" if inventory.find_by_host(fields["host"]) else "new"
        rows.append(PreviewRow(number, status, fields, password=password))
    return Preview(uuid.uuid4().hex, rows, clock())


@dataclass
class ApplyResult:
    added: int = 0
    updated: int = 0
    skipped: int = 0
    errors: int = 0


def apply_preview(preview: Preview, inventory: Inventory, secrets: SecretStore, *, overwrite: bool) -> ApplyResult:
    """오류 행은 빼고 등록한다. 등록 여부는 지금 목록 기준으로 다시 판단하고, 저장은 마지막에 한 번 한다."""
    result = ApplyResult()
    for row in preview.rows:
        if row.status == "error":
            result.errors += 1
            continue
        current = inventory.find_by_host(row.fields["host"])
        if current is not None and not overwrite:
            result.skipped += 1
            continue
        if current is None:
            server = inventory.add(row.fields)
            result.added += 1
        else:
            server = inventory.update(current.id, row.fields)
            result.updated += 1
        secrets.save(server.id, row.password)
    inventory.save()
    return result


class PreviewStore:
    """미리보기 결과를 메모리에만 잠시 둔다. 꺼내면 지워지고, ttl초가 지나도 지워진다."""

    def __init__(self, ttl: float = PREVIEW_TTL, clock: Callable[[], float] = time.monotonic) -> None:
        self._ttl = ttl
        self._clock = clock
        self._items: dict[str, Preview] = {}
        self._lock = threading.Lock()

    def put(self, preview: Preview) -> None:
        with self._lock:
            self._purge()
            self._items[preview.id] = preview

    def take(self, preview_id: str) -> Preview | None:
        with self._lock:
            self._purge()
            return self._items.pop(preview_id, None)

    def _purge(self) -> None:
        now = self._clock()
        for key in [k for k, p in self._items.items() if now - p.created > self._ttl]:
            del self._items[key]
```

```python
"""상태 점: 서버의 5985 포트가 TCP 연결을 받는지 병렬로 본다. 로그인은 하지 않는다."""

import asyncio
from collections.abc import Iterable

WINRM_PORT = 5985


async def _one(host: str, port: int, timeout: float) -> bool:
    try:
        _, writer = await asyncio.wait_for(asyncio.open_connection(host, port), timeout)
    except (OSError, TimeoutError):
        return False
    writer.close()
    try:
        await writer.wait_closed()
    except OSError:
        pass
    return True


async def _all(hosts: list[str], port: int, timeout: float) -> dict[str, bool]:
    results = await asyncio.gather(*(_one(h, port, timeout) for h in hosts))
    return dict(zip(hosts, results, strict=True))


def probe_all(hosts: Iterable[str], port: int = WINRM_PORT, timeout: float = 1.0) -> dict[str, bool]:
    unique = list(dict.fromkeys(hosts))
    if not unique:
        return {}
    return asyncio.run(_all(unique, port, timeout))
```

```python
"""이 PC의 WinRM TrustedHosts: 읽기, 포함 여부 판단, 관리자 권한(UAC)으로 추가."""

import base64
import ctypes
import fnmatch
import json
import subprocess
import winreg
from collections.abc import Callable, Iterable
from ctypes import wintypes
from enum import StrEnum

from hq.bootstrap import encoded_argv
from hq.paths import resource
from hq.validation import validate_host

CLIENT_KEY = r"SOFTWARE\Microsoft\Windows\CurrentVersion\WSMAN\Client"
CLIENT_VALUE = "trusted_hosts"
POLICY_KEY = r"SOFTWARE\Policies\Microsoft\Windows\WinRM\Client"
POLICY_VALUE = "TrustedHostsList"
_MISSING = object()


def parse_entries(value: str | None) -> list[str]:
    return [item.strip().lower() for item in (value or "").split(",") if item.strip()]


def is_trusted(host: str, entries: Iterable[str]) -> bool:
    name = host.strip().lower()
    for entry in entries:
        if entry in ("*", name):
            return True
        if "*" in entry and fnmatch.fnmatchcase(name, entry):
            return True
    return False


def missing_hosts(hosts: Iterable[str], entries: Iterable[str]) -> list[str]:
    known = list(entries)
    return [host for host in dict.fromkeys(hosts) if not is_trusted(host, known)]


def _registry_value(key_path: str, name: str) -> object:
    try:
        with winreg.OpenKey(winreg.HKEY_LOCAL_MACHINE, key_path) as key:
            value, _kind = winreg.QueryValueEx(key, name)
            return value
    except FileNotFoundError:
        return _MISSING


def read_trusted_hosts(reader: Callable[[str, str], object] = _registry_value) -> list[str] | None:
    """TrustedHosts 항목 목록. 설정한 적 없으면 []. 읽을 수 없으면 None(그때 hq는 사전 확인을 건너뛴다)."""
    try:
        policy = reader(POLICY_KEY, POLICY_VALUE)
        if policy is not _MISSING:
            return parse_entries(str(policy))
        value = reader(CLIENT_KEY, CLIENT_VALUE)
    except OSError:
        return None
    return [] if value is _MISSING else parse_entries(str(value))


def build_add_script(hosts: Iterable[str]) -> str:
    cleaned = [validate_host(h) for h in hosts]
    encoded = base64.b64encode(json.dumps(cleaned).encode("utf-8")).decode("ascii")
    template = resource("ps/add-trustedhosts.ps1").read_text(encoding="utf-8-sig")
    return template.replace("__HQ_HOSTS__", encoded)


class AddResult(StrEnum):
    OK = "ok"
    CANCELLED = "cancelled"
    FAILED = "failed"


def add_trusted_hosts(hosts: Iterable[str], run: Callable[[str, str], int | None] | None = None) -> AddResult:
    wanted = list(dict.fromkeys(hosts))
    if not wanted:
        return AddResult.OK
    argv = encoded_argv(build_add_script(wanted), no_exit=False)
    code = (run or run_elevated)(argv[0], subprocess.list2cmdline(argv[1:]))
    if code is None:
        return AddResult.CANCELLED
    return AddResult.OK if code == 0 else AddResult.FAILED


class _ShellExecuteInfo(ctypes.Structure):
    _fields_ = [
        ("cbSize", wintypes.DWORD),
        ("fMask", wintypes.ULONG),
        ("hwnd", wintypes.HWND),
        ("lpVerb", wintypes.LPCWSTR),
        ("lpFile", wintypes.LPCWSTR),
        ("lpParameters", wintypes.LPCWSTR),
        ("lpDirectory", wintypes.LPCWSTR),
        ("nShow", ctypes.c_int),
        ("hInstApp", wintypes.HINSTANCE),
        ("lpIDList", ctypes.c_void_p),
        ("lpClass", wintypes.LPCWSTR),
        ("hkeyClass", wintypes.HKEY),
        ("dwHotKey", wintypes.DWORD),
        ("hIconOrMonitor", wintypes.HANDLE),
        ("hProcess", wintypes.HANDLE),
    ]


_SEE_MASK_NOCLOSEPROCESS = 0x00000040
_SW_HIDE = 0
_ERROR_CANCELLED = 1223
_WAIT_MS = 120_000


def run_elevated(file: str, parameters: str) -> int | None:
    """UAC 확인을 받아 관리자 권한으로 실행하고 종료 코드를 돌려준다. 사용자가 취소하면 None."""
    shell32 = ctypes.WinDLL("shell32", use_last_error=True)
    kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)
    shell32.ShellExecuteExW.argtypes = [ctypes.POINTER(_ShellExecuteInfo)]
    shell32.ShellExecuteExW.restype = wintypes.BOOL
    kernel32.WaitForSingleObject.argtypes = [wintypes.HANDLE, wintypes.DWORD]
    kernel32.GetExitCodeProcess.argtypes = [wintypes.HANDLE, ctypes.POINTER(wintypes.DWORD)]
    kernel32.CloseHandle.argtypes = [wintypes.HANDLE]

    info = _ShellExecuteInfo()
    info.cbSize = ctypes.sizeof(info)
    info.fMask = _SEE_MASK_NOCLOSEPROCESS
    info.lpVerb = "runas"
    info.lpFile = file
    info.lpParameters = parameters
    info.nShow = _SW_HIDE
    if not shell32.ShellExecuteExW(ctypes.byref(info)):
        error = ctypes.get_last_error()
        if error == _ERROR_CANCELLED:
            return None
        raise ctypes.WinError(error)
    try:
        kernel32.WaitForSingleObject(info.hProcess, _WAIT_MS)
        code = wintypes.DWORD()
        kernel32.GetExitCodeProcess(info.hProcess, ctypes.byref(code))
        return code.value
    finally:
        kernel32.CloseHandle(info.hProcess)
```

```python
"""탭별 출력을 모아 두었다가 한 번에 화면으로 보낸다. 한 번에 보내는 양은 max_chars로 묶는다."""

import threading


class OutputBatcher:
    def __init__(self, max_chars: int = 200_000) -> None:
        self._max = max_chars
        self._pending: dict[str, list[str]] = {}
        self._size = 0
        self._lock = threading.Lock()

    def add(self, session_id: str, data: str) -> None:
        if not data:
            return
        with self._lock:
            self._pending.setdefault(session_id, []).append(data)
            self._size += len(data)

    def drain(self) -> dict[str, str]:
        with self._lock:
            out: dict[str, str] = {}
            budget = self._max
            for session_id in list(self._pending):
                if budget <= 0:
                    break
                parts = self._pending[session_id]
                taken: list[str] = []
                while parts and budget > 0:
                    chunk = parts[0]
                    if len(chunk) <= budget:
                        taken.append(parts.pop(0))
                        budget -= len(chunk)
                    else:
                        taken.append(chunk[:budget])
                        parts[0] = chunk[budget:]
                        budget = 0
                if taken:
                    out[session_id] = "".join(taken)
                if not parts:
                    del self._pending[session_id]
            self._size -= sum(len(v) for v in out.values())
            return out

    def discard(self, session_id: str) -> None:
        with self._lock:
            parts = self._pending.pop(session_id, [])
            self._size -= sum(len(p) for p in parts)

    def pending(self) -> int:
        with self._lock:
            return self._size
```

```python
import queue
import time


class FakePty:
    """feed()로 출력을 넣고 finish()로 끝낸다. 'exit\\r'을 받으면 스스로 끝난다(exit_on_exit=False면 버틴다)."""

    def __init__(self, *, exit_on_exit: bool = True) -> None:
        self._queue: queue.Queue[str | None] = queue.Queue()
        self._exit_on_exit = exit_on_exit
        self.written: list[str] = []
        self.alive = True
        self.exitstatus: int | None = None
        self.size: tuple[int, int] | None = None
        self.terminated = False

    def feed(self, text: str) -> None:
        self._queue.put(text)

    def finish(self, code: int) -> None:
        if self.alive:
            self.exitstatus = code
            self.alive = False
            self._queue.put(None)

    def read(self, size: int = 1024) -> str:
        item = self._queue.get()
        if item is None:
            self._queue.put(None)
            raise EOFError("closed")
        return item

    def write(self, text: str) -> int:
        self.written.append(text)
        if text == "exit\r" and self._exit_on_exit:
            self.finish(0)
        return len(text)

    def isalive(self) -> bool:
        return self.alive

    def setwinsize(self, rows: int, cols: int) -> None:
        self.size = (rows, cols)

    def terminate(self, force: bool = False) -> bool:
        self.terminated = True
        self.finish(1)
        return True


class FakeSpawner:
    def __init__(self, *, exit_on_exit: bool = True) -> None:
        self._exit_on_exit = exit_on_exit
        self.calls: list[tuple[list[str], int, int]] = []
        self.ptys: list[FakePty] = []

    def __call__(self, argv: list[str], rows: int, cols: int) -> FakePty:
        pty = FakePty(exit_on_exit=self._exit_on_exit)
        self.calls.append((argv, rows, cols))
        self.ptys.append(pty)
        return pty


def wait_for(condition, timeout: float = 2.0) -> bool:
    deadline = time.monotonic() + timeout
    while time.monotonic() < deadline:
        if condition():
            return True
        time.sleep(0.01)
    return bool(condition())
```

```python
"""서버 탭마다 powershell.exe 하나를 ConPTY 안에서 띄우고 끝날 때까지 관리한다.

세션마다 스레드 두 개를 둔다. 읽기 스레드는 출력을 계속 읽어 on_output으로 넘긴다(안 읽으면
자식 프로세스가 멈춘다). 감시 스레드는 isalive()로 끝남을 알아채 on_exit에 종료 코드를 넘긴다.
ConPTY는 프로세스가 끝난 뒤 EOF를 몇 초 늦게 내므로 EOF를 기다리지 않는다.
"""

import logging
import re
import threading
import time
from collections.abc import Callable, Iterable
from dataclasses import dataclass
from typing import Protocol

log = logging.getLogger(__name__)
_ID = re.compile(r"[0-9a-f]{32}")


class PtyLike(Protocol):
    exitstatus: int | None

    def read(self, size: int = ...) -> str: ...
    def write(self, s: str) -> object: ...
    def isalive(self) -> bool: ...
    def setwinsize(self, rows: int, cols: int) -> None: ...
    def terminate(self, force: bool = False) -> object: ...


Spawner = Callable[[list[str], int, int], PtyLike]


def spawn_conpty(argv: list[str], rows: int, cols: int) -> PtyLike:
    from winpty import PtyProcess

    return PtyProcess.spawn(argv, dimensions=(rows, cols))


class SessionError(Exception):
    pass


@dataclass
class _Session:
    id: str
    server_id: str
    pty: PtyLike
    generation: int = 0
    running: bool = True
    closing: bool = False


class SessionManager:
    def __init__(
        self,
        *,
        spawn: Spawner,
        on_output: Callable[[str, str], None],
        on_exit: Callable[[str, int | None], None],
        poll_interval: float = 0.2,
        drain_delay: float = 0.3,
        close_timeout: float = 2.0,
    ) -> None:
        self._spawn = spawn
        self._on_output = on_output
        self._on_exit = on_exit
        self._poll = poll_interval
        self._drain_delay = drain_delay
        self._close_timeout = close_timeout
        self._sessions: dict[str, _Session] = {}
        self._lock = threading.Lock()

    def open(self, session_id: str, server_id: str, argv: list[str], cols: int, rows: int) -> None:
        if not _ID.fullmatch(session_id or ""):
            raise SessionError(f"잘못된 세션 id: {session_id!r}")
        with self._lock:
            if session_id in self._sessions:
                raise SessionError("이미 열린 세션입니다.")
        pty = self._spawn(argv, rows, cols)
        session = _Session(session_id, server_id, pty)
        with self._lock:
            self._sessions[session_id] = session
        self._start(session, 0, pty)

    def reconnect(self, session_id: str, argv: list[str], cols: int, rows: int) -> None:
        with self._lock:
            session = self._sessions.get(session_id)
            if session is None:
                raise SessionError("닫힌 세션입니다.")
            if session.running:
                raise SessionError("아직 실행 중인 세션입니다.")
        self._on_output(session_id, f"\r\n\x1b[90m── 다시 연결 ({time.strftime('%H:%M:%S')}) ──\x1b[0m\r\n")
        pty = self._spawn(argv, rows, cols)
        with self._lock:
            session.generation += 1
            session.pty = pty
            session.running = True
            generation = session.generation
        self._start(session, generation, pty)

    def _start(self, session: _Session, generation: int, pty: PtyLike) -> None:
        tag = session.id[:8]
        threading.Thread(target=self._read_loop, args=(session, generation, pty), name=f"hq-read-{tag}",
                         daemon=True).start()
        threading.Thread(target=self._watch_loop, args=(session, generation, pty), name=f"hq-watch-{tag}",
                         daemon=True).start()

    def _read_loop(self, session: _Session, generation: int, pty: PtyLike) -> None:
        while True:
            try:
                data = pty.read(4096)
            except EOFError:
                return
            except Exception:
                log.exception("출력 읽기 실패 %s", session.id[:8])
                return
            if data and session.generation == generation and not session.closing:
                self._on_output(session.id, data)

    def _watch_loop(self, session: _Session, generation: int, pty: PtyLike) -> None:
        while pty.isalive():
            time.sleep(self._poll)
        time.sleep(self._drain_delay)  # 끝나기 직전 출력을 읽기 스레드가 마저 넘기도록 잠깐 기다린다
        code = pty.exitstatus
        with self._lock:
            if session.generation != generation:
                return
            session.running = False
            closing = session.closing
        if not closing:
            self._on_exit(session.id, code)

    def _get(self, session_id: str) -> _Session | None:
        with self._lock:
            return self._sessions.get(session_id)

    def write(self, session_id: str, data: str) -> None:
        session = self._get(session_id)
        if session is None or not session.running or session.closing:
            return
        try:
            session.pty.write(data)
        except Exception:
            log.debug("입력을 넘기지 못함 %s", session_id[:8], exc_info=True)

    def resize(self, session_id: str, cols: int, rows: int) -> None:
        session = self._get(session_id)
        if session is None or not session.running:
            return
        try:
            session.pty.setwinsize(rows, cols)
        except Exception:
            log.debug("크기를 바꾸지 못함 %s", session_id[:8], exc_info=True)

    def close(self, session_id: str) -> None:
        with self._lock:
            session = self._sessions.pop(session_id, None)
        if session is None:
            return
        session.closing = True
        pty = session.pty
        if not pty.isalive():
            return
        try:
            pty.write("\x03")  # 실행 중인 명령을 멈춘다
            time.sleep(0.1)
            pty.write("exit\r")  # 원격에서는 Exit-PSSession, 이어서 안전장치가 세션을 정리하고 끝낸다
        except Exception:
            log.debug("닫기 입력 실패 %s", session_id[:8], exc_info=True)
        deadline = time.monotonic() + self._close_timeout
        while pty.isalive() and time.monotonic() < deadline:
            time.sleep(0.05)
        if pty.isalive():
            try:
                pty.terminate(force=True)
            except Exception:
                log.warning("강제 종료 실패 %s", session_id[:8], exc_info=True)

    def close_many(self, session_ids: Iterable[str]) -> None:
        threads = [threading.Thread(target=self.close, args=(sid,), daemon=True) for sid in list(session_ids)]
        for thread in threads:
            thread.start()
        for thread in threads:
            thread.join()

    def close_all(self) -> None:
        with self._lock:
            ids = list(self._sessions)
        self.close_many(ids)

    def open_count(self) -> int:
        with self._lock:
            return len(self._sessions)

    def running_count(self) -> int:
        with self._lock:
            return sum(1 for s in self._sessions.values() if s.running)

    def sessions_for(self, server_id: str) -> list[str]:
        with self._lock:
            return [sid for sid, s in self._sessions.items() if s.server_id == server_id]

    def server_of(self, session_id: str) -> str | None:
        session = self._get(session_id)
        return session.server_id if session else None
```

  - `class Bridge(*, inventory, secrets, emit, dialogs, destroy, spawn=spawn_conpty, probe=probe_all, read_trusted=read_trusted_hosts, add_trusted=add_trusted_hosts, load_error=None, session_options=None)` — 공개 메서드는 화면 API뿐이다(아래 표). 반환값은 모두 `{"ok": bool, ...}` 모양이고 실패 때 `"error"`(한국어 문장), 사전 확인 실패 때 `"need"`(`"password" | "trustedhosts" | "unreachable"`), 취소 때 `"cancelled": True`가 붙는다.
  - 모듈 함수: `start_pump(bridge)`, `close_requested(bridge) -> bool`, `shutdown(bridge)`
  - hq → 화면 호출(JS): `window.hq.onOutput({세션id: 글자})`, `window.hq.onSessionEnded(세션id, 이유)`, `window.hq.onCloseRequested(탭 수)`

| 화면이 부르는 함수 | 돌려주는 것 |
|---|---|
| `list_servers()` | `servers: [{id,name,nickname,host,group,username,memo,has_password}]` |
| `add_server(info, password)` / `update_server(server_id, info)` | `server` |
| `set_password(server_id, password)` | — |
| `delete_server(server_id)` | `closed_sessions: [세션id]` |
| `probe()` | `status: {서버id: bool}` |
| `save_excel_template()` | `path` |
| `preview_excel()` | `preview_id, rows: [{row,status,name,nickname,host,group,username,error}], counts: {new,existing,error}` |
| `apply_excel(preview_id, overwrite)` | `added, updated, skipped, errors` |
| `missing_trusted_hosts()` | `readable: bool, missing: [host]` |
| `add_trusted_hosts()` | — |
| `server_setup_script(server_id, restrict)` | `script` |
| `get_settings()` / `save_settings(admin_ips)` | `admin_ips` |
| `open_session(session_id, server_id, cols, rows)` / `reconnect(session_id, cols, rows)` | — |
| `send_input(session_id, data)` / `resize(session_id, cols, rows)` | 없음(None) |
| `close_session(session_id)` | — |
| `quit()` | 없음 — 세션을 닫고 창을 없앤다 |

```python
"""화면(창 안의 JS)과 hq 본체 사이의 창구.

pywebview는 js_api로 넘긴 객체의 공개 메서드를 window.pywebview.api 로 내놓는다. 그래서 다른 모듈과
상태는 모두 밑줄(_)로 시작하는 이름에 둔다. 메서드는 받은 값을 확인해 해당 모듈에 넘기고 화면이
쓰기 쉬운 dict를 돌려준다. 판단 로직은 각 모듈에 있고 여기에는 두지 않는다.

창의 수명에 관한 함수(start_pump, close_requested, shutdown)는 화면에 내놓지 않으려고 메서드가
아니라 모듈 함수로 둔다.
"""

import json
import logging
import re
import threading
from collections.abc import Callable
from dataclasses import asdict
from pathlib import Path
from typing import Any, Protocol

from hq import excel
from hq.batcher import OutputBatcher
from hq.bootstrap import BootstrapParams, build_command, reason_for_exit
from hq.inventory import Inventory, InventoryError, Server
from hq.probe import probe_all
from hq.secret_store import SecretStore
from hq.server_setup import build_server_setup_script
from hq.sessions import SessionError, SessionManager, Spawner, spawn_conpty
from hq.trustedhosts import AddResult, missing_hosts, read_trusted_hosts
from hq.trustedhosts import add_trusted_hosts as add_hosts_elevated
from hq.validation import ValidationError

log = logging.getLogger(__name__)
_ID = re.compile(r"[0-9a-f]{32}")
PUMP_INTERVAL = 0.016
TEMPLATE_NAME = "hq-서버목록-양식.xlsx"


class Dialogs(Protocol):
    def open_xlsx(self) -> str | None: ...
    def save_xlsx(self, default_name: str) -> str | None: ...


def _fail(message: str, **extra: Any) -> dict[str, Any]:
    return {"ok": False, "error": message, **extra}


def _size(value: Any, default: int) -> int:
    try:
        return min(max(int(value), 2), 1000)
    except (TypeError, ValueError):
        return default


class Bridge:
    def __init__(
        self,
        *,
        inventory: Inventory,
        secrets: SecretStore,
        emit: Callable[[str], object],
        dialogs: Dialogs,
        destroy: Callable[[], object],
        spawn: Spawner = spawn_conpty,
        probe: Callable[[list[str]], dict[str, bool]] = probe_all,
        read_trusted: Callable[[], list[str] | None] = read_trusted_hosts,
        add_trusted: Callable[[list[str]], AddResult] = add_hosts_elevated,
        load_error: str | None = None,
        session_options: dict[str, float] | None = None,
    ) -> None:
        self._inventory = inventory
        self._secrets = secrets
        self._emit_js = emit
        self._dialogs = dialogs
        self._destroy = destroy
        self._probe = probe
        self._read_trusted = read_trusted
        self._add_trusted = add_trusted
        self._load_error = load_error
        self._batcher = OutputBatcher()
        self._sessions = SessionManager(
            spawn=spawn, on_output=self._batcher.add, on_exit=self._on_exit, **(session_options or {})
        )
        self._previews = excel.PreviewStore()
        self._emit_lock = threading.Lock()
        self._stop = threading.Event()
        self._quitting = False

    # ---------- 서버 목록 ----------
    def list_servers(self) -> dict[str, Any]:
        if self._load_error:
            return _fail(self._load_error)
        return {"ok": True, "servers": [self._public(s) for s in self._inventory.servers]}

    def add_server(self, info: dict[str, Any], password: str) -> dict[str, Any]:
        if self._load_error:
            return _fail(self._load_error)
        if not password:
            return _fail("PW를 입력하세요.")
        try:
            server = self._inventory.add(info)
        except ValidationError as exc:
            return _fail(str(exc))
        try:
            self._secrets.save(server.id, password)
            self._inventory.save()
        except (OSError, InventoryError) as exc:
            self._inventory.remove(server.id)
            self._secrets.delete(server.id)
            return _fail(f"저장하지 못했습니다: {exc}")
        log.info("서버 추가 %s", server.host)
        return {"ok": True, "server": self._public(server)}

    def update_server(self, server_id: str, info: dict[str, Any]) -> dict[str, Any]:
        if self._load_error:
            return _fail(self._load_error)
        try:
            server = self._inventory.update(server_id, info)
            self._inventory.save()
        except KeyError:
            return _fail("목록에 없는 서버입니다.")
        except ValidationError as exc:
            return _fail(str(exc))
        except (OSError, InventoryError) as exc:
            return _fail(f"저장하지 못했습니다: {exc}")
        return {"ok": True, "server": self._public(server)}

    def set_password(self, server_id: str, password: str) -> dict[str, Any]:
        if not password:
            return _fail("비밀번호를 입력하세요.")
        try:
            self._inventory.get(server_id)
            self._secrets.save(server_id, password)
        except KeyError:
            return _fail("목록에 없는 서버입니다.")
        except (OSError, ValueError) as exc:
            return _fail(f"저장하지 못했습니다: {exc}")
        return {"ok": True}

    def delete_server(self, server_id: str) -> dict[str, Any]:
        if self._load_error:
            return _fail(self._load_error)
        try:
            self._inventory.get(server_id)
        except KeyError:
            return _fail("목록에 없는 서버입니다.")
        closed = self._sessions.sessions_for(server_id)
        self._sessions.close_many(closed)
        for session_id in closed:
            self._batcher.discard(session_id)
        self._inventory.remove(server_id)
        self._secrets.delete(server_id)
        try:
            self._inventory.save()
        except (OSError, InventoryError) as exc:
            return _fail(f"저장하지 못했습니다: {exc}")
        log.info("서버 삭제 %s", server_id)
        return {"ok": True, "closed_sessions": closed}

    def probe(self) -> dict[str, Any]:
        servers = self._inventory.servers
        result = self._probe([s.host for s in servers])
        return {"ok": True, "status": {s.id: bool(result.get(s.host, False)) for s in servers}}

    # ---------- 엑셀 ----------
    def save_excel_template(self) -> dict[str, Any]:
        path = self._dialogs.save_xlsx(TEMPLATE_NAME)
        if not path:
            return {"ok": False, "cancelled": True}
        try:
            excel.write_template(Path(path))
        except OSError as exc:
            return _fail(f"저장하지 못했습니다(파일이 열려 있으면 닫으세요): {exc}")
        return {"ok": True, "path": path}

    def preview_excel(self) -> dict[str, Any]:
        if self._load_error:
            return _fail(self._load_error)
        path = self._dialogs.open_xlsx()
        if not path:
            return {"ok": False, "cancelled": True}
        try:
            preview = excel.build_preview(Path(path), self._inventory)
        except excel.ExcelError as exc:
            return _fail(str(exc))
        self._previews.put(preview)
        counts = {"new": 0, "existing": 0, "error": 0}
        rows = []
        for row in preview.rows:
            counts[row.status] += 1
            shown = {key: row.fields.get(key, "") for key in ("name", "nickname", "host", "group", "username")}
            rows.append({"row": row.row, "status": row.status, "error": row.error, **shown})
        return {"ok": True, "preview_id": preview.id, "rows": rows, "counts": counts}

    def apply_excel(self, preview_id: str, overwrite: bool) -> dict[str, Any]:
        preview = self._previews.take(str(preview_id))
        if preview is None:
            return _fail("미리보기가 만료되었습니다. 파일을 다시 고르세요.")
        try:
            result = excel.apply_preview(preview, self._inventory, self._secrets, overwrite=bool(overwrite))
        except (OSError, InventoryError, ValidationError) as exc:
            return _fail(f"등록하지 못했습니다: {exc}")
        log.info("엑셀 등록 %s", asdict(result))
        return {"ok": True, **asdict(result)}

    # ---------- 초기 설정 ----------
    def missing_trusted_hosts(self) -> dict[str, Any]:
        entries = self._read_trusted()
        if entries is None:
            return {"ok": True, "readable": False, "missing": []}
        hosts = [s.host for s in self._inventory.servers]
        return {"ok": True, "readable": True, "missing": missing_hosts(hosts, entries)}

    def add_trusted_hosts(self) -> dict[str, Any]:
        hosts = [s.host for s in self._inventory.servers]
        entries = self._read_trusted()
        wanted = hosts if entries is None else missing_hosts(hosts, entries)
        result = self._add_trusted(wanted)
        if result is AddResult.OK:
            return {"ok": True}
        if result is AddResult.CANCELLED:
            return _fail("취소했습니다.")
        return _fail("TrustedHosts를 설정하지 못했습니다. 관리자 권한 PowerShell에서 직접 설정하세요.")

    def server_setup_script(self, server_id: str, restrict: bool) -> dict[str, Any]:
        try:
            server = self._inventory.get(server_id)
        except KeyError:
            return _fail("목록에 없는 서버입니다.")
        ips = self._inventory.admin_ips if restrict else []
        if restrict and not ips:
            return _fail("설정 화면에서 관리자 PC IP를 먼저 저장하세요.")
        try:
            return {"ok": True, "script": build_server_setup_script(server.username, ips)}
        except ValidationError as exc:
            return _fail(str(exc))

    def get_settings(self) -> dict[str, Any]:
        return {"ok": True, "admin_ips": self._inventory.admin_ips}

    def save_settings(self, admin_ips: list[str]) -> dict[str, Any]:
        if self._load_error:
            return _fail(self._load_error)
        try:
            self._inventory.set_admin_ips([str(ip) for ip in admin_ips or []])
            self._inventory.save()
        except ValidationError as exc:
            return _fail(str(exc))
        except (OSError, InventoryError) as exc:
            return _fail(f"저장하지 못했습니다: {exc}")
        return {"ok": True, "admin_ips": self._inventory.admin_ips}

    # ---------- 세션 ----------
    def open_session(self, session_id: str, server_id: str, cols: int, rows: int) -> dict[str, Any]:
        session_id = str(session_id)
        if not _ID.fullmatch(session_id):
            return _fail("잘못된 세션 id입니다.")
        try:
            server = self._inventory.get(server_id)
        except KeyError:
            return _fail("목록에 없는 서버입니다.")
        problem = self._precheck(server)
        if problem:
            return problem
        try:
            self._sessions.open(session_id, server.id, self._command_for(server), _size(cols, 80), _size(rows, 24))
        except (SessionError, OSError) as exc:
            return _fail(f"PowerShell을 띄우지 못했습니다: {exc}")
        log.info("세션 열기 %s %s", session_id[:8], server.host)
        return {"ok": True}

    def reconnect(self, session_id: str, cols: int, rows: int) -> dict[str, Any]:
        session_id = str(session_id)
        server_id = self._sessions.server_of(session_id)
        if server_id is None:
            return _fail("닫힌 탭입니다.")
        try:
            server = self._inventory.get(server_id)
        except KeyError:
            return _fail("이 서버는 목록에서 지워졌습니다.")
        problem = self._precheck(server)
        if problem:
            return problem
        try:
            self._sessions.reconnect(session_id, self._command_for(server), _size(cols, 80), _size(rows, 24))
        except (SessionError, OSError) as exc:
            return _fail(f"다시 연결하지 못했습니다: {exc}")
        log.info("다시 연결 %s %s", session_id[:8], server.host)
        return {"ok": True}

    def send_input(self, session_id: str, data: str) -> None:
        if isinstance(data, str):
            self._sessions.write(str(session_id), data)

    def resize(self, session_id: str, cols: int, rows: int) -> None:
        self._sessions.resize(str(session_id), _size(cols, 80), _size(rows, 24))

    def close_session(self, session_id: str) -> dict[str, Any]:
        self._sessions.close(str(session_id))
        self._batcher.discard(str(session_id))
        return {"ok": True}

    def quit(self) -> None:
        self._quitting = True
        shutdown(self)
        self._destroy()

    # ---------- 내부 ----------
    def _public(self, server: Server) -> dict[str, Any]:
        return {
            "id": server.id,
            "name": server.name,
            "nickname": server.nickname,
            "host": server.host,
            "group": server.group,
            "username": server.username,
            "memo": server.memo,
            "has_password": self._secrets.has(server.id),
        }

    def _command_for(self, server: Server) -> list[str]:
        params = BootstrapParams(
            host=server.host,
            username=server.username,
            nickname=server.display_name,
            secret_path=str(self._secrets.path_for(server.id)),
        )
        return build_command(params)

    def _precheck(self, server: Server) -> dict[str, Any] | None:
        if not self._secrets.has(server.id):
            return _fail("저장된 비밀번호가 없습니다.", need="password")
        entries = self._read_trusted()
        if entries is not None and missing_hosts([server.host], entries):
            return _fail("초기 설정 필요: 이 PC의 TrustedHosts에 서버가 없습니다.", need="trustedhosts")
        if not self._probe([server.host]).get(server.host, False):
            return _fail(f"서버 응답 없음: {server.host}:5985", need="unreachable")
        return None

    def _emit(self, script: str) -> None:
        try:
            self._emit_js(script)
        except Exception:
            log.debug("화면에 보내지 못함(창이 닫히는 중일 수 있음)", exc_info=True)

    def _flush(self) -> None:
        with self._emit_lock:
            batch = self._batcher.drain()
            if batch:
                self._emit(f"window.hq.onOutput({json.dumps(batch)})")

    def _on_exit(self, session_id: str, code: int | None) -> None:
        reason = reason_for_exit(code)
        log.info("세션 끝남 %s %s (코드 %s)", session_id[:8], reason.value, code)
        with self._emit_lock:
            while batch := self._batcher.drain():  # 끝나기 전 출력이 먼저 화면에 가도록
                self._emit(f"window.hq.onOutput({json.dumps(batch)})")
            self._emit(f"window.hq.onSessionEnded({json.dumps(session_id)}, {json.dumps(reason.value)})")


def start_pump(bridge: Bridge) -> None:
    """출력을 약 16ms마다 묶어 화면에 보낸다. pywebview가 창을 띄운 뒤 부른다."""

    def loop() -> None:
        while not bridge._stop.wait(PUMP_INTERVAL):
            bridge._flush()

    threading.Thread(target=loop, name="hq-pump", daemon=True).start()


def close_requested(bridge: Bridge) -> bool:
    """창을 닫아도 되면 True. 열린 탭이 있으면 화면에 확인을 부탁하고 False(닫기 취소)."""
    if bridge._quitting:
        return True
    count = bridge._sessions.open_count()
    if count == 0:
        return True
    # 닫기 이벤트는 창 스레드에서 오므로 화면 호출은 다른 스레드에서 한다
    threading.Thread(target=bridge._emit, args=(f"window.hq.onCloseRequested({count})",), daemon=True).start()
    return False


def shutdown(bridge: Bridge) -> None:
    bridge._sessions.close_all()
    bridge._stop.set()
```

```js
/* 화면의 순수 로직. DOM을 건드리지 않는다.
   브라우저에서는 window.HQ 로, node 테스트에서는 require() 로 쓴다(file:// 에서는 ES 모듈을 쓸 수 없다). */
(function (root, factory) {
  const api = factory();
  if (typeof module === 'object' && module.exports) module.exports = api;
  else root.HQ = api;
})(typeof self !== 'undefined' ? self : this, function () {
  'use strict';

  const UNGROUPED = '미분류';

  function displayName(server) {
    return server.nickname || server.name;
  }

  function filterServers(servers, query) {
    const q = (query || '').trim().toLowerCase();
    if (!q) return servers.slice();
    return servers.filter((s) => [s.name, s.nickname, s.host, s.memo].some((v) => (v || '').toLowerCase().includes(q)));
  }

  function groupServers(servers) {
    const groups = new Map();
    for (const server of servers) {
      const name = server.group || UNGROUPED;
      if (!groups.has(name)) groups.set(name, []);
      groups.get(name).push(server);
    }
    const names = [...groups.keys()].sort((a, b) => {
      if (a === UNGROUPED) return 1;
      if (b === UNGROUPED) return -1;
      return a.localeCompare(b, 'ko');
    });
    return names.map((name) => ({
      name,
      servers: groups.get(name).slice().sort((a, b) => displayName(a).localeCompare(displayName(b), 'ko')),
    }));
  }

  function nextOrdinal(used) {
    let ordinal = 1;
    while (used.includes(ordinal)) ordinal += 1;
    return ordinal;
  }

  function tabTitle(server, ordinal) {
    return ordinal <= 1 ? displayName(server) : `${displayName(server)} (${ordinal})`;
  }

  function pastedLineCount(text) {
    return (text || '').split(/\r\n|\r|\n/).filter((line) => line.trim() !== '').length;
  }

  function needsPasteConfirm(text) {
    return pastedLineCount(text) > 1;
  }

  function shortcutFor(e) {
    const key = (e.key || '').toLowerCase();
    if (e.key === 'F5' || (e.ctrlKey && !e.altKey && key === 'r')) return { type: 'block' };
    if (e.ctrlKey && e.key === 'Tab') return { type: e.shiftKey ? 'prev' : 'next' };
    if (e.ctrlKey && !e.shiftKey && !e.altKey && key === 'k') return { type: 'search' };
    if (e.altKey && !e.ctrlKey && /^Digit[1-9]$/.test(e.code || '')) return { type: 'index', index: Number(e.code.slice(5)) - 1 };
    return null;
  }

  function statusView(online) {
    if (online === true) return { label: '온라인', cls: 'on' };
    if (online === false) return { label: '응답 없음', cls: 'off' };
    return { label: '확인 전', cls: 'unknown' };
  }

  const ACTION_LABELS = {
    reconnect: '다시 연결',
    retry: '다시 시도',
    password: '비밀번호 입력',
    setup: '서버 설정 스크립트',
    trust: '설정하기',
  };
  const ENDED = {
    USER_EXIT: { short: '세션 종료', text: '세션을 종료했습니다.', actions: ['reconnect'] },
    AUTH_FAILED: {
      short: '로그인 거부',
      text: '로그인 거부: 비밀번호가 틀렸거나, Administrator가 아닌 로컬 계정이면 서버에 원격 관리자 설정이 필요합니다.',
      actions: ['password', 'setup'],
    },
    UNREACHABLE: {
      short: '응답 없음',
      text: '서버 응답 없음: WinRM이 꺼져 있거나 5985가 막혀 있을 수 있습니다.',
      actions: ['retry', 'setup'],
    },
    NOT_TRUSTED: { short: '초기 설정 필요', text: '초기 설정 필요: 이 PC의 TrustedHosts에 서버가 없습니다.', actions: ['trust'] },
    QUOTA: {
      short: '세션 한도 초과',
      text: '서버의 동시 세션 한도 초과: 다른 탭을 닫거나 서버 설정 스크립트로 한도를 올리세요.',
      actions: ['retry', 'setup'],
    },
    SECRET_UNREADABLE: {
      short: '비밀번호 읽기 실패',
      text: '저장된 비밀번호를 읽을 수 없습니다(PC나 계정이 바뀜). 다시 입력하세요.',
      actions: ['password'],
    },
    DISCONNECTED: { short: '연결 끊김', text: '연결이 끊겼습니다.', actions: ['reconnect'] },
    UNKNOWN: { short: '알 수 없는 오류', text: '알 수 없는 오류입니다. 위 터미널의 오류 내용을 확인하세요.', actions: ['reconnect'] },
  };

  function endedView(reason) {
    const view = ENDED[reason] || ENDED.UNKNOWN;
    return { short: view.short, text: view.text, actions: view.actions.map((id) => ({ id, label: ACTION_LABELS[id] })) };
  }

  /* pywebview는 화면이 부른 함수마다 스레드를 따로 띄워 순서가 바뀔 수 있다.
     그래서 앞 호출이 끝난 뒤에 다음을 보내고, 그사이 들어온 입력은 묶어서 보낸다. */
  function createInputQueue(send) {
    let buffer = '';
    let busy = false;
    function flush() {
      if (busy || !buffer) return;
      const data = buffer;
      buffer = '';
      busy = true;
      Promise.resolve()
        .then(() => send(data))
        .catch(() => {})
        .finally(() => {
          busy = false;
          flush();
        });
    }
    return {
      push(data) {
        buffer += data;
        flush();
      },
      pending() {
        return buffer;
      },
    };
  }

  function newId() {
    const bytes = new Uint8Array(16);
    globalThis.crypto.getRandomValues(bytes);
    return Array.from(bytes, (b) => b.toString(16).padStart(2, '0')).join('');
  }

  return {
    UNGROUPED,
    displayName,
    filterServers,
    groupServers,
```

```js
   사용자 자료(서버 이름, 별명, 메모 등)는 항상 textContent나 텍스트 노드로만 넣는다. */
(function () {
  'use strict';

  const L = window.HQ;
  const $ = (selector) => document.querySelector(selector);
  const USERNAME_HINT = '서버의 로컬 계정. 예) Administrator, opsadmin';
  const TERM_THEME = {
    background: '#0a0d12',
    foreground: '#d6dde8',
    cursor: '#e8eef7',
    cursorAccent: '#0a0d12',
    selectionBackground: '#2a3d5a',
  };

  const state = { servers: [], status: {}, query: '', selected: null, view: 'servers', tabs: [], active: null };
  let api = null;
  let closeCurrentModal = null;

  // ---------- 도우미 ----------
  function h(tag, props, ...children) {
    const node = document.createElement(tag);
    for (const [key, value] of Object.entries(props || {})) {
      if (value === undefined || value === null || value === false) continue;
      if (key === 'class') node.className = value;
      else if (key === 'text') node.textContent = value;
      else if (key.startsWith('on') && typeof value === 'function') node.addEventListener(key.slice(2), value);
      else node.setAttribute(key, value === true ? '' : String(value));
    }
    for (const child of children.flat(Infinity)) {
      if (child !== null && child !== undefined && child !== false) node.append(child);
    }
    return node;
  }

  function serverById(id) {
    return state.servers.find((s) => s.id === id);
  }

    return state.tabs.find((t) => t.sid === sid);

  async function copyText(text) {
    try {
      await navigator.clipboard.writeText(text);
      return true;
    } catch (error) {
      return false;
    }
  }

  // ---------- 대화 상자 ----------
  function openModal({ title, body, buttons, wide }) {
    if (closeCurrentModal) closeCurrentModal(undefined);
    return new Promise((resolve) => {
      const overlay = $('#modal');
      let primary = null;
      function close(value) {
        overlay.hidden = true;
        overlay.replaceChildren();
        document.removeEventListener('keydown', onKey, true);
        closeCurrentModal = null;
        resolve(value);
      }
      function onKey(event) {
        if (event.key === 'Escape') {
          event.preventDefault();
          event.stopPropagation();
          close(undefined);
        } else if (event.key === 'Enter' && event.target.tagName === 'INPUT' && event.target.type !== 'checkbox' && primary) {
          event.preventDefault();
          primary.click();
        }
      }
      const footer = h('div', { class: 'modal-actions' }, buttons.map((b) => {
        const button = h('button', { class: 'btn' + (b.primary ? ' primary' : '') + (b.danger ? ' danger' : ''), type: 'button', text: b.label });
        button.addEventListener('click', async () => {
          let value = b.value;
          if (b.run) {
            button.disabled = true;
            try {
              value = await b.run();
            } finally {
              button.disabled = false;
            }
            if (value === false) return;
          }
          close(value);
          if (b.after) b.after();
        });
        if (b.primary) primary = button;
        return button;
      }));
      overlay.replaceChildren(h('div', { class: 'modal-card' + (wide ? ' wide' : ''), role: 'dialog', 'aria-modal': 'true', 'aria-label': title },
        h('h2', { text: title }), body, footer));
      overlay.hidden = false;
      closeCurrentModal = close;
      document.addEventListener('keydown', onKey, true);
      const focusTarget = overlay.querySelector('input:not([type=checkbox]), textarea') || primary;
      if (focusTarget) focusTarget.focus();
    });
  }

  function confirmDialog({ title, message, ok, danger }) {
    return openModal({
      title,
      body: h('p', { class: 'msg', text: message }),
      buttons: [{ label: '취소', value: false }, { label: ok, value: true, primary: true, danger }],
    }).then((value) => value === true);
  }

  function messageDialog(title, message, extra = []) {
    return openModal({
      title,
      body: h('p', { class: 'msg', text: message }),
      buttons: [...extra.map((b) => ({ label: b.label, after: b.run })), { label: '닫기', primary: true }],
    });
  }

  function field(id, label, input, hint) {
    return h('label', { class: 'field', for: id }, h('span', { class: 'field-label', text: label }), input,
      hint ? h('span', { class: 'hint', text: hint }) : null);
  }

  // ---------- hq → 화면 ----------
  window.hq = {
    onOutput(batch) {
      for (const sid of Object.keys(batch)) {
        const tab = tabById(sid);
        if (!tab || !tab.term) continue;
        tab.term.write(batch[sid]);
        if (sid !== state.active && !tab.unread) {
          tab.unread = true;
          renderTabs();
        }
      }
    },
    onSessionEnded(sid, reason) {
      const tab = tabById(sid);
      if (tab) setEnded(tab, reason);
    },
    onCloseRequested(count) {
      confirmDialog({ title: 'HQ 끝내기', message: `열린 탭 ${count}개를 닫고 끝낼까요?`, ok: '끝내기', danger: true })
        .then((yes) => { if (yes) api.quit(); });
    },
  };

  async function loadServers() {
    const result = await api.list_servers();
    const box = $('#load-error');

    const button = $('#refresh');
    button.disabled = true;
    try {
      const result = await api.probe();
      if (result.ok) state.status = result.status;
    } finally {
      button.disabled = false;
    }
    renderServers();
  }

  async function refreshTrust() {
    const result = await api.missing_trusted_hosts();
    const banner = $('#banner');
    const missing = result.ok && result.readable ? result.missing : [];
    if (!missing.length) {
      banner.hidden = true;
      banner.replaceChildren();
      return;
    }
    banner.replaceChildren(
      h('span', { text: `초기 설정 필요: 이 PC의 TrustedHosts에 서버 ${missing.length}대가 없습니다.` }),
      h('button', { class: 'btn', type: 'button', text: '설정하기', onclick: trustNow }));
    banner.hidden = false;
  }

  async function trustNow() {
    const result = await api.add_trusted_hosts();
    await refreshTrust();
    if (state.view === 'settings') renderSettings();
    messageDialog('초기 설정', result.ok ? 'TrustedHosts에 서버를 추가했습니다.' : result.error);
  }

      nickname: h('input', { id: 'f-nickname', value: s.nickname || '', maxlength: '50' }),

    inputs.memo.value = s.memo || '';
    const password = editing ? null : h('input', { id: 'f-password', type: 'password', autocomplete: 'off' });
    const error = h('p', { class: 'form-error', role: 'alert' });
    const body = h('div', { class: 'form' },

      field('f-nickname', '별명', inputs.nickname, '비우면 이름을 보여 줍니다.'),

      field('f-group', '그룹', inputs.group),

      password ? field('f-password', 'PW *', password, '저장한 뒤에는 다시 볼 수 없습니다.') : null,
      field('f-memo', '메모', inputs.memo),

    await loadServers();
  }

  function openTab(server) {
    closeInfo();
    const used = state.tabs.filter((t) => t.serverId === server.id).map((t) => t.ordinal);
    const ordinal = L.nextOrdinal(used);
    const tab = {
      sid: L.newId(), serverId: server.id, ordinal, title: L.tabTitle(server, ordinal),
      ended: null, unread: false, memoOpen: false, size: null, term: null,
    };
    buildPane(tab);
    state.tabs.push(tab);
    activate(tab.sid);
    createTerminal(tab); // 보이는 상태에서 열어야 글자 크기를 제대로 잰다
    startSession(tab, 'open');
  }

    tab.nameText.textContent = L.displayName(server);
    tab.hostText.textContent = server.host;
    tab.memoLine.hidden = !memo;
    tab.memoLine.textContent = (tab.memoOpen ? '▾ ' : '▸ ') + memo.split('\n')[0];
    tab.memoFull.textContent = memo;
    tab.memoFull.hidden = !(tab.memoOpen && memo);
  }

  function createTerminal(tab) {
    tab.term = new Terminal({
      fontFamily: '"Cascadia Mono", Consolas, "Malgun Gothic", monospace',
      fontSize: 14,
      lineHeight: 1.15,
      cursorBlink: true,
      scrollback: 10000,
      theme: TERM_THEME,
    });
    tab.fit = new FitAddon.FitAddon();
    tab.term.loadAddon(tab.fit);
    tab.term.open(tab.termHost);
    tab.input = L.createInputQueue((data) => api.send_input(tab.sid, data));
    tab.term.onData((data) => { if (!tab.ended) tab.input.push(data); });
    tab.term.attachCustomKeyEventHandler((event) => terminalKey(tab, event));
    tab.termHost.addEventListener('paste', (event) => onPaste(tab, event), true);
    new ResizeObserver(() => fitTab(tab)).observe(tab.termHost);
    fitTab(tab);
  }

  function fitTab(tab) {
    if (!tab.term || tab.pane.hidden) return;
    try {
      tab.fit.fit();
    } catch (error) {
      return;
    }
    const size = `${tab.term.cols}x${tab.term.rows}`;
    if (size !== tab.size) {
      tab.size = size;
      if (!tab.ended) api.resize(tab.sid, tab.term.cols, tab.term.rows);
    }
  }

  async function startSession(tab, mode) {
    fitTab(tab);
    const cols = tab.term.cols;
    const rows = tab.term.rows;
    const result = mode === 'open'
      ? await api.open_session(tab.sid, tab.serverId, cols, rows)
      : await api.reconnect(tab.sid, cols, rows);
    if (result.ok) {
      setEnded(tab, null);
      tab.term.focus();
      return;
    }
    const server = serverById(tab.serverId);
    if (mode === 'open') removeTab(tab.sid); // 프로세스를 띄우지 않았으므로 탭을 닫는다
    if (!server) {
      messageDialog('접속할 수 없음', result.error);
      return;
    }
    const retry = () => (mode === 'open' ? openTab(server) : startSession(tab, 'reconnect'));
    if (result.need === 'password') {
      if (await passwordDialog(server, '저장된 비밀번호가 없습니다. 입력하면 바로 접속합니다.')) retry();
    } else if (result.need === 'trustedhosts') {
      messageDialog('초기 설정 필요', `${result.error}\n관리자 권한으로 이 PC의 TrustedHosts에 서버를 추가합니다.`, [{ label: '설정하기', run: trustNow }]);
    } else if (result.need === 'unreachable') {
      messageDialog('서버 응답 없음', `${result.error}\nWinRM이 꺼져 있거나 방화벽이 5985를 막고 있을 수 있습니다.`,
        [{ label: '서버 설정 스크립트', run: () => setupScriptDialog(server) }]);
    } else {
      messageDialog('접속할 수 없음', result.error || '알 수 없는 오류');
    }
  }

  function setEnded(tab, reason) {
    tab.ended = reason;
    tab.term.options.disableStdin = Boolean(reason);
    if (!reason) {
      tab.dot.className = 'dot run';
      tab.stateText.textContent = '실행 중';
      tab.overlay.hidden = true;
      tab.overlay.replaceChildren();
      renderTabs();
      return;
    }
    const view = L.endedView(reason);
    tab.dot.className = 'dot end';
    tab.stateText.textContent = '끝남: ' + view.short;
    tab.overlay.replaceChildren(h('div', { class: 'ended-card', role: 'alert' },
      h('p', { text: view.text }),
      h('div', { class: 'row' }, view.actions.map((action) => h('button', {
        class: 'btn', type: 'button', text: action.label, onclick: () => endedAction(tab, action.id),
      })))));
    tab.overlay.hidden = false;
    renderTabs();
  }

  async function endedAction(tab, id) {
    const server = serverById(tab.serverId);
    if (!server) {
      messageDialog('서버 없음', '이 서버는 목록에서 지워졌습니다.');
      return;
    }
    if (id === 'reconnect' || id === 'retry') startSession(tab, 'reconnect');
    else if (id === 'password') {
      if (await passwordDialog(server, '새 비밀번호를 저장하고 다시 연결합니다.')) startSession(tab, 'reconnect');
    } else if (id === 'setup') setupScriptDialog(server);
    else if (id === 'trust') trustNow();
  }

  function activate(sid) {
    state.active = sid;
    for (const tab of state.tabs) tab.pane.hidden = tab.sid !== sid;
    const tab = tabById(sid);
    if (tab) {
      tab.unread = false;
      requestAnimationFrame(() => {
        fitTab(tab);
        if (tab.term) tab.term.focus();
      });
    }
    renderTabs();
  }

  function renderTabs() {
    const bar = $('#tabbar');
    bar.replaceChildren(...state.tabs.map((tab) => h('div', {
      class: 'tab' + (tab.sid === state.active ? ' active' : ''),
      role: 'tab',
      'aria-selected': tab.sid === state.active ? 'true' : 'false',
      onclick: () => activate(tab.sid),
    },
    h('span', { class: 'dot ' + (tab.ended ? 'end' : 'run') }),
    h('span', { class: 'tab-title', text: tab.title }),
    tab.unread ? h('span', { class: 'unread', title: '새 출력' }) : null,
    h('button', {
      class: 'tab-close', type: 'button', title: '탭 닫기', 'aria-label': '탭 닫기', text: '×',
      onclick: (event) => { event.stopPropagation(); closeTab(tab.sid); },
    }))));
    $('#empty').hidden = state.tabs.length > 0;
  }

  function removeTab(sid) {
    const index = state.tabs.findIndex((t) => t.sid === sid);
    if (index < 0) return;
    const [tab] = state.tabs.splice(index, 1);
    if (tab.term) tab.term.dispose();
    tab.pane.remove();
    if (state.active === sid) {
      state.active = null;
      const next = state.tabs[index] || state.tabs[index - 1];
      if (next) activate(next.sid);
    }
    renderTabs();
  }

  function closeTab(sid) {
    removeTab(sid);
    api.close_session(sid);
  }

  function cycleTab(step) {
    if (!state.tabs.length) return;
    const index = state.tabs.findIndex((t) => t.sid === state.active);
    activate(state.tabs[(index + step + state.tabs.length) % state.tabs.length].sid);
  }

  function terminalKey(tab, event) {
    if (event.type !== 'keydown') return true;
    const key = (event.key || '').toLowerCase();
    if (event.ctrlKey && !event.altKey && !event.shiftKey && key === 'c' && tab.term.hasSelection()) {
      copyText(tab.term.getSelection());
      tab.term.clearSelection();
      event.preventDefault();
      return false;
    }
    if (event.ctrlKey && !event.altKey && key === 'v') return false; // 브라우저 붙여넣기로 넘겨 paste 이벤트에서 처리한다
    return true;
  }

  function onPaste(tab, event) {
    const text = event.clipboardData ? event.clipboardData.getData('text') : '';
    if (!L.needsPasteConfirm(text)) return; // 한 줄은 xterm이 그대로 붙여넣는다
    event.preventDefault();
    event.stopImmediatePropagation();
    const server = serverById(tab.serverId) || { name: '?', host: '?' };
    confirmDialog({
      title: '여러 줄 붙여넣기',
      message: `${L.displayName(server)}(${server.host})에 ${L.pastedLineCount(text)}줄을 실행합니다.`,
      ok: '실행',
    }).then((yes) => {
      if (yes && !tab.ended) tab.term.paste(text);
      tab.term.focus();
    });
  }

  // ---------- 전체 단축키와 시작 ----------
  document.addEventListener('keydown', (event) => {
    const shortcut = L.shortcutFor(event);
    if (shortcut && shortcut.type === 'block') {
      event.preventDefault(); // 새로고침하면 화면이 초기화되므로 막는다
      return;
    }
    if (!$('#modal').hidden) return;
    if (!shortcut) {
      if (event.key === 'Escape') {
        closeInfo();
        hideMenu();
      }
      return;
    }
    event.preventDefault();
    event.stopPropagation();
    if (shortcut.type === 'next') cycleTab(1);
    else if (shortcut.type === 'prev') cycleTab(-1);
    else if (shortcut.type === 'index') {
      const tab = state.tabs[shortcut.index];
      if (tab) activate(tab.sid);
    } else if (shortcut.type === 'search') {
      setView('servers');
      $('#search').focus();
      $('#search').select();
    }
  }, true);
  document.addEventListener('click', hideMenu);
  document.addEventListener('contextmenu', (event) => {
    if (!event.target.closest('.srv')) {
      event.preventDefault();
      hideMenu();
    }
  });

  function bindChrome() {
    $('#rail-servers').addEventListener('click', () => setView('servers'));
    $('#rail-settings').addEventListener('click', () => setView('settings'));
    $('#refresh').addEventListener('click', refreshStatus);
    $('#add-server').addEventListener('click', () => serverDialog(null));
    $('#excel').addEventListener('click', excelStart);
    $('#search').addEventListener('input', (event) => {
      state.query = event.target.value;
      renderServers();
    });
    window.addEventListener('resize', () => {
      const tab = tabById(state.active);
      if (tab) fitTab(tab);
    });
  }

  function ready(start) {
    if (window.pywebview && window.pywebview.api) start();
    else window.addEventListener('pywebviewready', start, { once: true });
  }

  ready(async () => {
    api = window.pywebview.api;
    bindChrome();
    await loadServers();
    refreshStatus();
    refreshTrust();
  });
})();
```

```python
"""HQ 실행: 단일 실행 확인, 로그, 창 만들기, 닫기 처리."""

import ctypes
import logging
import logging.handlers
from collections.abc import Callable
from ctypes import wintypes
from pathlib import Path
from typing import Any

import webview

from hq import paths
from hq.bridge import Bridge, close_requested, shutdown, start_pump
from hq.inventory import Inventory, InventoryError
from hq.secret_store import SecretStore

WINDOW_TITLE = "HQ"
MUTEX_NAME = "Local\\hq-single-instance"
XLSX_FILTER = ("Excel 파일 (*.xlsx)",)
log = logging.getLogger("hq")

_kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)
_user32 = ctypes.WinDLL("user32", use_last_error=True)
_kernel32.CreateMutexW.argtypes = [ctypes.c_void_p, wintypes.BOOL, wintypes.LPCWSTR]
_kernel32.CreateMutexW.restype = wintypes.HANDLE
_kernel32.CloseHandle.argtypes = [wintypes.HANDLE]
_user32.FindWindowW.argtypes = [wintypes.LPCWSTR, wintypes.LPCWSTR]
_user32.FindWindowW.restype = wintypes.HWND
_user32.IsIconic.argtypes = [wintypes.HWND]
_user32.ShowWindow.argtypes = [wintypes.HWND, ctypes.c_int]
_user32.SetForegroundWindow.argtypes = [wintypes.HWND]
_ERROR_ALREADY_EXISTS = 183
_SW_RESTORE = 9
_SW_SHOW = 5


def acquire_single_instance(name: str = MUTEX_NAME) -> int | None:
    """이미 실행 중이면 None. 아니면 프로세스가 끝날 때까지 쥐고 있을 뮤텍스 핸들."""
    ctypes.set_last_error(0)
    handle = _kernel32.CreateMutexW(None, False, name)
    if ctypes.get_last_error() == _ERROR_ALREADY_EXISTS:
        _kernel32.CloseHandle(handle)
        return None
    return handle


def release_single_instance(handle: int) -> None:
    _kernel32.CloseHandle(handle)


def bring_existing_to_front(title: str = WINDOW_TITLE) -> bool:
    hwnd = _user32.FindWindowW(None, title)
    if not hwnd:
        return False
    _user32.ShowWindow(hwnd, _SW_RESTORE if _user32.IsIconic(hwnd) else _SW_SHOW)
    _user32.SetForegroundWindow(hwnd)
    return True


def configure_logging(log_dir: Path) -> logging.handlers.RotatingFileHandler:
    log_dir.mkdir(parents=True, exist_ok=True)
    handler = logging.handlers.RotatingFileHandler(
        log_dir / "hq.log", maxBytes=1_000_000, backupCount=2, encoding="utf-8"
    )
    handler.setFormatter(logging.Formatter("%(asctime)s %(levelname)s %(name)s: %(message)s"))
    root = logging.getLogger()
    root.setLevel(logging.INFO)
    root.addHandler(handler)
    return handler


class WindowDialogs:
    """pywebview 창의 Windows 파일 대화 상자. bridge.Dialogs를 구현한다."""

    def __init__(self, get_window: Callable[[], Any]) -> None:
        self._get_window = get_window

    @staticmethod
    def _first(result: Any) -> str | None:
        if not result:
            return None
        return result if isinstance(result, str) else result[0]

    def open_xlsx(self) -> str | None:
        window = self._get_window()
        return self._first(window.create_file_dialog(webview.FileDialog.OPEN, file_types=XLSX_FILTER))

    def save_xlsx(self, default_name: str) -> str | None:
        window = self._get_window()
        result = window.create_file_dialog(webview.FileDialog.SAVE, save_filename=default_name, file_types=XLSX_FILTER)
        return self._first(result)


def stay_on_index(window: Any, index_url: str) -> None:
    """창이 웹 주소로 이동했으면 hq 화면으로 되돌린다."""
    url = window.get_current_url() or ""
    if url.startswith(("http://", "https://")):
        log.warning("hq 화면 밖으로 이동해서 되돌림: %s", url)
        window.load_url(index_url)


def main() -> None:
    data = paths.data_dir()
    configure_logging(data / "logs")
    mutex = acquire_single_instance()
    if mutex is None:
        bring_existing_to_front()
        return
    inventory = Inventory(data / "inventory.json")
    load_error = None
    try:
        inventory.load()
    except InventoryError as exc:
        load_error = str(exc)
        log.error(load_error)
    holder: dict[str, Any] = {}
    bridge = Bridge(
        inventory=inventory,
        secrets=SecretStore(data / "secrets"),
        emit=lambda script: holder["window"].evaluate_js(script),
        dialogs=WindowDialogs(lambda: holder["window"]),
        destroy=lambda: holder["window"].destroy(),
        load_error=load_error,
    )
    index = paths.index_url()
    webview.settings["SHOW_DEFAULT_MENUS"] = False
    webview.settings["ALLOW_DOWNLOADS"] = False
    window = webview.create_window(
        WINDOW_TITLE, url=index, js_api=bridge, width=1280, height=820, min_size=(960, 600),
        background_color="#0d1016", text_select=True,
    )
    holder["window"] = window
    window.events.closing += lambda: close_requested(bridge)
    window.events.loaded += lambda: stay_on_index(window, index)
    log.info("HQ 시작")
    try:
        webview.start(start_pump, (bridge,), debug=False, private_mode=True, icon=str(paths.resource("assets/hq.ico")))
    finally:
        shutdown(bridge)
        release_single_instance(mutex)
        log.info("HQ 끝")
```
